# CLEAN·ON 理

청렴 소식과 직접 만든 콘텐츠를 모아두는 개인 아카이브 사이트입니다.

## 폴더 구성

| 파일·폴더 | 하는 일 | 직접 고칠 일 |
|---|---|---|
| index.html | 사이트 화면 | 없음 |
| assets/ | 로고 이미지 | 로고 원본이 생기면 같은 이름으로 교체 |
| data/news.json | 소식 목록 | 관리 화면에서 수정 |
| data/contents.json | 콘텐츠 목록 | 관리 화면에서 수정 |
| media/ | 관리 화면에서 올린 이미지·파일이 저장되는 곳 | 없음 |
| .pages.yml | 관리 화면(Pages CMS) 설정 | 없음 |

## 글 올리는 법

1. https://app.pagescms.org 에 접속해서 GitHub로 로그인합니다.
2. 저장소를 고르고 왼쪽 메뉴에서 "소식" 또는 "콘텐츠"를 누릅니다.
3. 항목을 추가하고 칸을 채운 뒤 저장합니다.
4. 1~2분 뒤 사이트에 반영됩니다.

## 지켜야 할 것

- 이 저장소는 공개 상태입니다. 개인정보나 업무 자료는 올리지 않습니다.
- 기사 본문이나 이미지는 옮기지 않고, 요약과 원문 링크만 남깁니다.
